# Публикация в канал

Только по явному запросу владельца. Сначала используй актуальный раздел
«Стиль постов Коломбины» в PERSONA.md. Изменение стиля — только по просьбе
владельца; дефолт восстанавливается из отдельного резервного раздела там же.
Не меняй личность или остальные разделы под видом настройки постов.

1. Подготовь Telegram HTML и настоящие переносы строк. Ключевую мысль выдели
   `<blockquote>...</blockquote>`. Используй ID премиум-эмодзи из каталога.
2. Оставь место в подписи фото (общий лимит 1024 символа) для нижней строки:
   `<tg-emoji emoji-id="5300994163100119559">🌸</tg-emoji> ➢ @username_канала | #тег1 #тег2 #тег3`.
   Адрес канала берётся из реальной цели, не из выдуманного названия.
3. Вызови `prepare_channel_post_preview(chat_id, post_text, visual_query)`.
   Инструмент запускает Pinterest-поиск, собирает нумерованный контакт-лист
   изображений Коломбины. Рассмотри изображения, выбери лучший номер по теме.
   Не утверждай, что видела картинку, если изображение не получено/не просмотрено.
4. Вызови `bot_api_call(method="send_message", params={...})` с явным chat_id
   канала, текстом HTML, `post_preview_id` и `post_image_index` из результата.
   Мост создаст фото-черновик в личном чате владельца, а не сразу пост в канале.
5. При `channel_delivery="draft_created"` возьми реальные `reply_chat_id`,
   `reply_to_message_id`, `forward_chat_id` из ответа инструмента.
6. Вторым `send_message` отправь свои мысли реплаем к черновику:
   `chat_id=reply_chat_id`, `reply_parameters={"message_id": reply_to_message_id}`.
7. Вызови `forward_message` с `chat_id=forward_chat_id`,
   `from_chat_id=reply_chat_id`, `message_id=reply_to_message_id`.
8. Только успешная пересылка подтверждает публикацию. Не повторяй полный пост
   или дополнительное обычное подтверждение после уже отправленного комментария.

Учёт использованных URL ведёт мост в `data/post_images.json`. При провале поиска,
ошибке инструмента или утрате черновика остановись и сообщи точный статус.
Не повторяй публикацию вслепую: сначала проверь, не была ли она уже выполнена.
