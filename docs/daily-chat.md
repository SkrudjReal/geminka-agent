# Ежедневная реплика в группах

По умолчанию включена: `DAILY_CHAT_ENABLED=true`; `false` отключает после
перезапуска. Работает внутри процесса бота, отдельный cron не нужен.
В каждой разрешённой через `/chats` или `/topic` группе планируется одно
случайное время за календарный день в локальном часовом поясе процесса.
Первый запуск выбирает время из оставшейся части дня. Пропущенные дни не догоняются.
Несколько топиков одной группы не создают несколько отправок; если настроены
только топики, сообщение идёт в один из них.

Топ-10 активности берётся за последние сутки. Сначала проверяется наличие
сообщений каждого кандидата в других группах/каналах. Если такие авторы есть,
выбор идёт только среди них; иначе допускаются авторы только текущего чата.
Выбирается случайный автор с известным
username: с вероятностью 70% человек, 30% бот, затем случайный автор внутри
выбранной категории (сама Geminka исключена). Если есть только одна категория,
выбирается она. Тип берётся из `profile.is_bot` коллектора, не из имени.
MCP собирает его историю,
частые фразы и контекст ответов в этой группе. История и тематический поиск по
точному sender_user_id сначала ищут в других доступных группах/каналах с
public_only=true и exclude_chat_id чата назначения. Только при пустой истории
в других чатах поиск переключается на текущий чат. Лички исключены. Отдельный одноразовый
AGY-запрос в групповой песочнице пишет сообщение, не имея токенов архива/бота.
Текст задачи: `agent_skills/geminka/references/daily-chat.md`.
PERSONA.md не изменяется. При отсутствии подходящих фактов отправка пропускается.

Модель возвращает JSON с дословной цитатой и ID источника, естественной подводкой и
единым ироничным комментарием. Код проверяет автора, ID сообщения и совпадение
цитаты с оригиналом, отбрасывает пересылки. Если бот состоит в чате-источнике,
используется ReplyParameters с ID исходного чата и сообщения (включая ответы между
чатами), без дублирования текста цитаты. Иначе цитата выводится в blockquote,
без reply_parameters. Чужие источники из MCP не отбрасываются из-за отсутствия
бота в чате. Режим выбирается до отправки; неудачные отправки не повторяются.
переиначивание вплетается в комментарий без подписей «архив» и «перевод».
Обрывок ответа или выдуманная цитата не отправляются.

Во время тестов автопубликация отключена в приватном `.env`:
`DAILY_CHAT_ENABLED=false` (применяется после перезапуска).
Просмотр без Telegram-доставки и изменения расписания:
`uv run python -m app.services.daily_chat --chat-id -1001234567890`.
Опциональный `--user-id 123456` выбирает конкретного участника из топ-10.

Состояние: `data/daily_chat.json`, не попадает в Git. Попытка отмечается до
генерации и доставки: автоматического повтора в тот же день нет даже после
ошибки или перезапуска. Это защита от дублей, а не гарантия доставки:
сбой может оставить группу без сообщения на день. Удаление группы из настроек
останавливает будущие отправки. Для работы бот должен оставаться запущенным.
