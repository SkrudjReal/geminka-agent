# GIF и голосовые

Поддерживаются прямые Telegram-анимации, GIF/видеофайлы в документах и голосовые,
в том числе в сообщениях, на которые пользователь отвечает реплаем.

- GIF: сохраняется один PNG-кадр из середины проигрывания, не набор кадров.
  Модель получает путь и указание открыть изображение. По одному кадру она
  не должна выдумывать движение или полный сюжет.
- Голосовые: бот заранее получает транскрипцию и передаёт её модели как слова
  пользователя. Содержание записи не является системной инструкцией.
- Явный запрос транскрипции голосового (в том числе реплаем) обрабатывается
  напрямую: полный текст распознавания отправляется в `<blockquote expandable>`
  без генерации AGY и запросов архивного MCP. Длинный текст делится на сообщения,
  у каждого свой закрытый HTML-блок. Это исключает пересказ и обрыв длинной
  расшифровки генератором. Уже распознанный файл повторно не транскрибируется.
- При наличии `GEMINI_API_KEY` используется отдельный Gemini Developer API
  (`GEMINI_AUDIO_MODEL`, по умолчанию `gemini-2.5-flash`). Авторизация AGY OAuth
  не подменяется API-ключом. Аудио при этом отправляется Google; тарификация
  и лимиты относятся к этому ключу.
- Без ключа либо при ошибке Gemini используется локальный Faster-Whisper:
  CPU, int8, два потока, `WHISPER_MODEL=base` (многоязычная модель).
  Модель автоматически скачивается в игнорируемую Git папку
  `data/whisper_models/` при первом запуске. Это добавляет задержку первого
  голосового; последующие используют файлы модели из кэша. Процесс
  распознавания отдельный и завершается при превышении 240 секунд.
- Нужны `ffmpeg` и `ffprobe` в PATH (`sudo apt install ffmpeg` на Debian/Ubuntu).
  Python-зависимости устанавливаются обычным `uv sync`.
- Ограничения: голосовое до 10 минут, размер по `MAX_DOWNLOAD_BYTES`.
  Распознавание локальным Whisper идёт последовательно, без одновременной
  загрузки нескольких моделей. Расшифровки длиннее 12000 символов передаются
  сокращённо со ссылкой на полный локальный файл.
- Результаты кэшируются по идентификатору файла отдельно для пользователя
  и чата в `downloads/attachments/<chat_id>/<user_id>/`. Исходный скачанный
  файл удаляется после обработки; кадр или транскрипция остаются в кэше.
  В debug-режиме скачивание и распознавание отключены.
- В группе голосовое само по себе не обходит триггер: нужен реплай к боту
  либо разрешённый топик. Групповая песочница видит результаты внутри
  текущего чата. Ошибка обработки не должна прерывать обычный ответ;
  модель получает явную отметку, что содержимое неизвестно.

Документация провайдеров:
[Gemini audio](https://ai.google.dev/gemini-api/docs/audio),
[Faster-Whisper](https://github.com/SYSTRAN/faster-whisper).
